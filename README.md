# RA130 Stick Builder -- クイックスタート

ワイヤーフレームメッシュを、ロボットが接着組み立てできるスティック(棒材)のセットに変換します。


## 1. インストール

1. Blender **5.2 LTS 以降**が必要です(`bl_info` ではなく Extensions プラットフォームを使用)。
2. `so100_builder/` フォルダを zip 圧縮します(すでに `.zip` があればそれを使用)。
3. `Edit > Preferences > Get Extensions > (ドロップダウン) > Install from Disk...` から作成した zip を選択します。
4. 3D ビューポートのサイドバーに **RA130** という新しいタブが表示されます(`N` キーで開きます)。

## 2. シーンを準備する

**デザイン**パネルで:

1. **ロボット** -- 対象のロボットを選択します。
2. **ベース** -- ロボットの原点を示すエンプティを追加します。ロボットが実際に設置される位置に移動・回転させてください。
3. **メッシュ** -- ワイヤーフレームメッシュを選択します(1エッジ = 1スティック)。
4. **ストック**(Stock、スティックの断面)と **スティック長**(Stick Length)の設定を確認します。デフォルトのままでも構いません。
5. **メッシュ展開**(Mesh Expansion)内で `ビルドプレートを要求`(Require Build Plate)が有効な場合、**ビルドプレートに落とす**(Drop to Build Plate)を使ってスティック抽出前にメッシュをビルドプレートに接地させます。

## 3. スティックを抽出する

**スティックを抽出**(Extract Sticks)をクリックします。固定長のスティックが各接合部でグルー(接着)の隙間を保ちながら収まるようにデザインを拡張し、各スティックの長さ・ステータス・警告を一覧表示します。

- 隣のゴミ箱アイコンは結果(生成済みのビルドメッシュを含む)をクリアします。これにより最初から再抽出できます。
- **オーバーレイを表示**(Show Overlay)を切り替えると、ビューポート上にビルドボリューム / ベースボックスが表示されます。

## 4. ビルド順序を計算する

**プラン**パネルで **組み立て順序を計算**をクリックします。すべての配置がロボットの実際の運動学(キネマティクス)に対して検証され、エラーや警告が報告されます。

ロボットは1レイヤーずつ組み立て、各レイヤー内では遠い側から手前側へ向かって作業します。そのため、まだ設置すべきスティックへの経路を自分で塞いでしまうことがありません。デザインの各段の間隔が1センチメートルより狭い場合は、**レイヤー高さ許容値**(Layer Height Tolerance、デザイン ▸ 詳細設定)をそれに合わせて小さくしてください。

- **スティック**(Sticks)パネルで、ビルド位置が決まったスティックは **前に移動 / 後に移動**(Move Before / Move After)で手動でも並び替えられます。


## 5. スティックを確認する

**スティック**(Sticks)パネルで行を選択すると、そのスティックの長さ・残差・警告が表示されます。

- **目視確認**(Check By Eye)はそのスティックのエッジにビューポートをフレーミングし、ハイライト表示します。
- **以前のスティックをハイライト**(Highlight Previous Sticks、目視確認の上にあるチェックボックス)を有効にすると、そのスティックより前に配置されたスティックも薄くハイライトされ、組み立ての進行状況を一目で確認できます。
- 左右の矢印で前後のスティックに移動できます。

## 6. エクスポートしてビルドする

**ビルド**(Build)パネルで:

1. **ビルドファイルを書き出し**(Export Build File)で、別プロセスの ROS2 側が読み込むビルドファイルを書き出します(このアドオンはロボットへのライブ接続を持たず、ビルドファイルが唯一の連携手段です)。
